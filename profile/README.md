# Ocean Networks Canada

Ocean Networks Canada (ONC), hosted by the University of Victoria, runs cabled, mobile and community-based ocean observatories on the Pacific, Atlantic and Arctic coasts of Canada and in the Southern Ocean. The data are free to use. The tools and notebooks here show you how.

## Choose your path

### Use ONC data in code
For researchers and developers who want ONC data in their own analysis.

- **Python:** [api-python-client](https://github.com/OceanNetworksCanada/api-python-client) ([docs](https://oceannetworkscanada.github.io/api-python-client/))
- **MATLAB:** [api-matlab-client](https://github.com/OceanNetworksCanada/api-matlab-client)
- **Visualization:** [oncdw](https://github.com/OceanNetworksCanada/oncdw) ([docs](https://oceannetworkscanada.github.io/oncdw/)), a Python library for visualizing Oceans 3.0 data

### Learn with the data
For students, educators and anyone new to ocean data.

- Work through example Jupyter notebooks in [python-community-notebooks](https://github.com/OceanNetworksCanada/python-community-notebooks)
- Read guides in the [Oceans 3.0 Knowledge Base](https://wiki.oceannetworks.ca/spaces/O2KB/overview)

> **Oceans 3.0 is the starting point for ONC data.** Explore it in the [Oceans 3.0 data portal](https://data.oceannetworks.ca). The API, which the tools and notebooks above use, needs a **free account and API token**: [get your API token](https://wiki.oceannetworks.ca/spaces/O2KB/pages/59015680/Get+your+API+token). A free account also lets you save searches and plots, keep your data requests longer, share plots, and get support follow-up from ONC.


## What data is there?

There are hundreds of data products, grouped into a few main families:

- **Sound:** hydrophone recordings
- **Seismic:** seafloor seismic data
- **Seafloor video:** video from seafloor cameras
- **Sensor measurements:** time series such as temperature and pressure

You don't need to know them all. [Data Products Home](https://wiki.oceannetworks.ca/spaces/DP/pages/18939907/Data+Products+Home) lists what's available.
